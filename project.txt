RAG Chatbot (NotebookLM-like)

Users can send messages and files to the chatbot.
The chatbot prompts the LLM with related context from the vector DB (RAG).

Vector DB stores:
- uploaded file chunks
- user messages
- assistant answers

Backend APIs:
- POST /api/upload (file parsing, chunking, embedding, upsert into Qdrant)
- POST /api/chat (non-stream completion)
- POST /api/chat/stream (streaming completion)
- GET /api/history/{conversation_id}
- GET /api/files/{conversation_id}
- GET /api/health

OpenAI-compatible APIs (for Open WebUI integration):
- GET /v1/models
- POST /v1/chat/completions (supports stream true/false)

Technologies:
- vector DB: Qdrant
- model runtime: Ollama (embedding + LLM)
- backend: Python (FastAPI)
- frontend: React App
- deployment: Docker Compose

Infrastructure:
- Docker Compose services: qdrant, ollama-init, backend
- Ollama runtime: host machine (Windows), accessed from containers via host.docker.internal:11434
